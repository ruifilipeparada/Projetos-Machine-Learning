# Projetos de Machine Learning 

## Objetivo

Este repositório reúne projetos **extracurriculares** desenvolvidos na área de **Machine Learning**. Os projetos académicos são armazenados nos repositórios **Mestrado-Business-Intelligence** e **PG-Business-Analytics**. 

---

## Descrição

Este repositório funciona como uma coleção de projetos independentes relacionados com **Machine Learning** e **Data Science**.

Os projetos exploram diferentes etapas do desenvolvimento de modelos preditivos, desde a análise e preparação dos dados até à construção, avaliação e otimização dos modelos.

Entre os principais temas abordados encontram-se:

* Data Analysis
* Data Processing
* Feature Engineering
* Model Building
* Model Evaluation
* Hyperparameter Tuning
* Machine Learning

Cada projeto possui a sua própria estrutura e documentação, com uma descrição das abordagens utilizadas e dos objetivos definidos.

---

## Linguagem e Ferramentas

* **Linguagem:** Python
* **Machine Learning:** Scikit-learn / outras bibliotecas utilizadas em cada projeto
* **Data Analysis:** Pandas, NumPy
* **Visualização:** Matplotlib / outras bibliotecas utilizadas em cada projeto
* **Editor:** VS Code
* **Controlo de versões:** Git / GitHub
